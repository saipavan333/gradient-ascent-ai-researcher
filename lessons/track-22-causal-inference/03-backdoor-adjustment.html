Backdoor adjustment: computing do() from data

You usually can't run the experiment. Backdoor adjustment is the recipe that recovers the causal effect — the do() answer — from ordinary observational data, by adjusting for exactly the right confounders and no others.

The do-operator (Lesson 2) told us what we want — \(P(Y \mid do(T))\), the effect of intervening — but computing it seemed to require an experiment we often can't run (too costly, too slow, unethical). The remarkable result of causal inference is that, under the right conditions, you can compute the interventional \(do\) answer from purely observational data. The recipe is backdoor adjustment, and it makes precise the "compare within subgroups" intuition from the confounding lesson. A confounder creates a backdoor path — a non-causal route from treatment \(T\) to outcome \(Y\) that runs backward through the confounder (\(T \leftarrow Z \to Y\)). This path lets \(Z\)'s influence leak into the naive comparison. Backdoor adjustment blocks that path by conditioning on \(Z\): compute the treatment effect within each value of \(Z\), then average those effects weighted by how common each \(Z\) is. Blocking the backdoor leaves only the genuine causal path \(T \to Y\), so the adjusted estimate equals the true \(do\) effect. The subtlety — and the reason you need a causal graph, not just data — is knowing which variables to adjust for: adjust for confounders (good), but adjusting for the wrong variables can create bias. This lesson builds the recipe and its crucial caveat.

💡 Intuition: close the side door

Think of two doors connecting treatment \(T\) and outcome \(Y\). The front door is the honest causal path \(T \to Y\) — the effect you want. The back door is a sneaky side route \(T \leftarrow Z \to Y\) through the confounder, which lets correlation flow between \(T\) and \(Y\) without any causation. The naive comparison sees the sum of both doors, which is why it's biased. Backdoor adjustment simply closes the back door: by looking only within groups that share the same \(Z\), the confounder can't vary, so its route is blocked, and only the front-door causal effect remains. Averaging the within-group effects (weighted by group size) reassembles the population-level causal effect with the confounding removed.

The backdoor adjustment formula:

\[ P(Y \mid do(T=t)) \;=\; \sum_{z} P(Y \mid T=t,\, Z=z)\,P(Z=z) \] (3.1)

Read it: to get the interventional distribution, look at the outcome within each confounder stratum \(Z=z\) — that's \(P(Y\mid T=t, Z=z)\), a like-with-like comparison — and average across strata, weighting each by its natural frequency \(P(Z=z)\). The key difference from naive conditioning is the weighting: we weight by \(P(z)\), the confounder's distribution in the whole population, not by \(P(z\mid t)\) (which would reintroduce the imbalance). That reweighting is what simulates setting \(T\) while leaving \(Z\)'s natural spread intact — exactly \(do(T)\). It works if \(Z\) blocks all backdoor paths and you've measured it (the "backdoor criterion").

✍️ Worked example: recovering the true effect

From backdoor.py: \(Z\to T\), \(Z\to Y\), \(T\to Y\); the true effect of \(T\) is +5.

1
Naive. \(E[Y\mid T{=}1] - E[Y\mid T{=}0] = +17\). Confounded — the backdoor \(T\leftarrow Z\to Y\) is wide open.
2
Within each stratum. Among \(Z{=}0\): effect ≈ +5. Among \(Z{=}1\): effect ≈ +5. Blocking \(Z\) reveals the true effect in each group.
3
Average, weighted by \(P(Z)\). \(P(Z{=}0)=P(Z{=}1)=0.5\), so adjusted \(= 0.5(5) + 0.5(5) = +4.97\) — the true effect.
4
Result. Naive +17 → adjusted +4.97, from observational data alone, no experiment. Backdoor adjustment computed the \(do\) answer by closing the confounding path.

🛠️ From scratch: backdoor adjustment

naive = Y[T==1].mean() - Y[T==0].mean()          # +17  (backdoor open)

adj = 0.0
for z in (0, 1):
    pz    = (Z == z).mean()                       # P(Z=z) in the whole population
    eff_z = Y[(T==1)&(Z==z)].mean() - Y[(T==0)&(Z==z)].mean()   # effect WITHIN stratum z
    adj  += pz * eff_z                            # average, weighted by P(z)  (eq 3.1)
# adj = +4.97  ==  true effect (5)

The loop is equation (3.1): within-stratum effects, averaged by the confounder's population frequency. For a continuous confounder you'd use regression or the propensity methods of the next lesson instead of a sum, but the principle is identical — block the backdoor by holding the confounder fixed.

The deadly caveat: don't adjust for the wrong thing. Backdoor adjustment is only correct for a set \(Z\) that blocks all backdoor paths without opening new ones — the formal "backdoor criterion." Adjust for a confounder (common cause): good. But adjust for a mediator (a variable on the causal path \(T\to M\to Y\)) and you remove part of the real effect. Adjust for a collider (a common effect, \(T\to C\leftarrow Y\)) and you create a spurious association out of nothing. This is why you cannot just "control for everything" — the choice of what to adjust for requires the causal graph, and getting it wrong turns a fix into a new bias. Which variables are safe is precisely what the causal diagram tells you.

⚠️ Mistakes everyone makes here

  • Controlling for everything. Adjusting for mediators or colliders introduces bias. Only adjust for a valid backdoor set (confounders), which the graph identifies.
  • Weighting by \(P(z\mid t)\) instead of \(P(z)\). The population weight \(P(z)\) is what simulates the intervention; the conditional weight would keep the confounding.
  • Assuming you measured all confounders. Backdoor adjustment only blocks confounders you have. An unmeasured confounder leaves a backdoor open, and the estimate stays biased.
  • Forgetting positivity. You need some treated and some untreated units in every stratum. If a stratum has only treated (or only untreated) units, you can't compare within it.

🔑 Key results to remember

  • A backdoor path (\(T\leftarrow Z\to Y\)) is a non-causal route that biases the naive estimate.
  • Backdoor adjustment blocks it: effect within each \(Z\) stratum, averaged by \(P(Z)\) (eq 3.1) — this equals \(P(Y\mid do(T))\).
  • Weight by \(P(z)\), not \(P(z\mid t)\) — that's what simulates the intervention.
  • Adjust only for a valid backdoor set (confounders); mediators and colliders introduce bias — you need the graph.
  • Requires measuring all confounders and positivity (both treatments present in each stratum).

Q1. What is a "backdoor path"?

  • The direct causal path from T to Y.
    That's the front door — the effect you want to keep.
  • A non-causal path from T to Y through a confounder (T ← Z → Y).
    Correct. It leaks confounding into the naive comparison.
  • A path from Y to T.
    Backdoor paths specifically run through a common cause.
  • The learning rate schedule.
    Unrelated.

Q2. How does backdoor adjustment recover the causal effect?

  • By collecting more data.
    It's about how you compute, not data volume.
  • By deleting the confounder.
    You condition on it, not delete it.
  • Effect within each confounder stratum, averaged by P(Z).
    Correct. Blocking Z within strata, then averaging by the population weight, equals do(T).
  • By training a deeper model.
    Model depth doesn't remove confounding.

Q3. Why is "control for everything" a bad strategy?

  • It's too slow.
    The problem is bias, not speed.
  • It always underfits.
    Not the issue.
  • It uses too much memory.
    Not the concern here.
  • Adjusting for mediators or colliders introduces new bias.
    Correct. Only a valid backdoor set (confounders) is safe; the graph tells you which.

Q4. What must be true for backdoor adjustment to give the right answer?

  • You measured all confounders that block the backdoor paths.
    Correct. Unmeasured confounders leave a backdoor open and bias remains.
  • The treatment is binary.
    It works for many treatment types.
  • There is no causal effect.
    It estimates whatever effect exists, including nonzero.
  • The dataset is small.
    Size isn't the requirement; measuring confounders is.

✍️ Practice

1. (warm-up) In the interactive, press "Adjust for Z." How far does the estimate move, and toward what value? What did adjusting accomplish?

Show solution

The estimate jumps from the confounded naive value down to about +5, the true causal effect. Adjusting for Z closed the backdoor path T ← Z → Y: instead of comparing treated vs untreated across the whole (imbalanced) population, you compared them within each Z stratum — where Z is held fixed and can't confound — then averaged those honest within-group effects by the population frequency of each Z. That reweighting is what turns a biased observational comparison into the interventional do(T) answer, recovering the truth from data alone. It's the concrete, computable version of "compare like with like."

2. (transfer) A "collider" is a common effect of T and Y (T → C ← Y). Why does adjusting for a collider create a spurious association, unlike adjusting for a confounder?

Show solution

A collider starts blocked: with no conditioning, the path T → C ← Y doesn't transmit association (two arrows crashing into C don't connect T and Y). But conditioning on the collider C opens it, inducing a dependence between T and Y that wasn't there. Intuition: if C is caused by both T and Y, then learning C constrains the combination of T and Y — e.g., if C = "hospitalized" and both a disease (Y) and an injury (T) can cause hospitalization, then among hospitalized people, not having the injury makes the disease more likely (something had to explain the hospitalization). So controlling for C manufactures a T–Y correlation from nothing (this is "collider bias" or selection bias). That's the opposite of a confounder, where the path is open by default and conditioning closes it. The takeaway: adjusting isn't universally good — for confounders it removes bias, for colliders it creates bias — and only the causal graph tells you which role a variable plays. "Control for everything" can be actively harmful.

3. (stretch) Backdoor adjustment needs you to have measured the confounders. What can you do when a key confounder is unmeasured?

Show solution

Several strategies, each with assumptions. (1) Instrumental variables: find a variable that affects T but influences Y only through T (and isn't confounded with Y) — like a random encouragement or a policy change — and use it to isolate T's effect despite the unmeasured confounder. (2) Front-door adjustment: if you can measure a full mediator M on the path T → M → Y that is itself unconfounded with Y, Pearl's front-door formula recovers the effect even with an unmeasured T–Y confounder. (3) Difference-in-differences / regression discontinuity / natural experiments: exploit timing or thresholds that mimic randomization. (4) Sensitivity analysis: rather than claim a point estimate, quantify how strong an unmeasured confounder would have to be to overturn your conclusion. (5) Best of all, run a randomized experiment, which needs no confounder to be measured. The honest stance is that with unmeasured confounding the effect may not be identifiable from the data at all — so you either find a clever design that sidesteps it or you bound how wrong you could be. Recognizing when your confounders are incomplete is itself a crucial skill.

🚀 In the real world & at the frontier

Backdoor adjustment (and its generalizations) is the everyday workhorse of causal inference in epidemiology, economics, social science, and tech experimentation, letting analysts estimate effects from observational data when experiments are impossible. Software like DoWhy and CausalML implements it and checks the assumptions. The frontier combines adjustment with machine learning — "double machine learning" and causal forests use flexible models to adjust for many, possibly high-dimensional confounders while still delivering valid causal estimates with error bars — and grapples with high-dimensional and unstructured confounders (adjusting for the information in an image or a text record). The enduring lesson is that the hard part isn't the arithmetic; it's knowing the causal structure well enough to choose what to adjust for. That judgment — encoded in a causal graph — is what separates a credible causal claim from a confidently wrong one.

Recap — say it to a friend

"A confounder opens a backdoor path T ← Z → Y that biases the naive comparison. Backdoor adjustment closes it: compute the effect within each level of Z, then average weighted by how common each Z is — and that equals the do() effect, from observational data alone. The catch is you must adjust for the right variables (confounders, not mediators or colliders) and have measured them all — which requires the causal graph, not just the numbers."
