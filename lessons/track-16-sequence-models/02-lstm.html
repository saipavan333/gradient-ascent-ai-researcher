LSTM: a memory the gradient can travel

The LSTM solved long-term memory with one elegant idea: a memory lane that updates by addition, not by repeated multiplication — so the learning signal has a highway to travel back on. Small "gates" decide what to keep, what to write, and what to read.

Track 8 · Lesson 2 Concept + code + interactive ~28 min Builds on: Lessons 0–1

Vanishing gradients doomed the plain RNN on long sequences. The Long Short-Term Memory cell — LSTM, from Hochreiter & Schmidhuber in 1997 — fixes it with a second memory called the cell state. Unlike the ordinary hidden state, the cell state is changed only by gentle, mostly-additive edits as it flows through time, instead of being run through a fresh multiplication-and-squash every step. That additive path is a "highway" the gradient can travel without shrinking, and it's what finally let recurrent networks remember things hundreds of steps back.

💡 Intuition: a conveyor belt with three valves

Picture a conveyor belt running left to right through the cell — that belt is the cell state, carrying memory forward. Three little valves control it, and each valve is a gate: a number between 0 (fully closed) and 1 (fully open), computed by the network. The forget gate decides how much of what's on the belt to keep versus wipe. The input gate decides how much new information to place onto the belt. The output gate decides how much of the belt's contents to reveal as this step's answer. Because the belt is mostly just carried forward (and only nudged by these valves), information — and the gradient — can ride it a long way without fading.

The gates are each a sigmoid (written \(\sigma\)) — a function that squashes any number into the 0-to-1 range, perfect for a "how open is this valve?" dial. The candidate new content is a \(\tanh\). Here are the four little computations from the current input \(x\) and previous answer \(h\):

\[ f=\sigma(W_f[x,h]),\; i=\sigma(W_i[x,h]),\; g=\tanh(W_g[x,h]),\; o=\sigma(W_o[x,h]) \] (2.1)

And here is the one line that matters most — how the belt updates and what gets read off it (\(\odot\) just means "multiply element by element"):

\[ c_t = f\odot c_{t-1} + i\odot g, \qquad h_t = o\odot\tanh(c_t). \] (2.2)

Read \(c_t = f\odot c_{t-1} + i\odot g\) in words: "new memory = (how much to keep) × old memory + (how much to write) × new stuff." When the network wants to remember, it opens the forget gate (\(f\approx1\)) and the old memory is passed forward almost untouched — added to, not multiplied-and-squashed. That means the step-to-step factor for the gradient is about \(f\approx 1\): the highway the previous lesson said we needed.

✍️ Worked example: keep a memory for 5 steps

Let one memory cell hold the value 1, written at step 0. Say the network learned to keep it: forget gate \(f=1\), input gate \(i=0\) (write nothing new). Watch the belt.

1
Step 1: \(c_1 = f\cdot c_0 + i\cdot g = 1\cdot 1 + 0 = 1\). Unchanged.
2
Steps 2–5: the same each time — \(c = 1\cdot 1 + 0 = 1\). After 5 steps the memory is still exactly 1. After 500 steps it would still be exactly 1.
3
Compare to a plain RNN. There the memory was multiplied-and-squashed each step (0.96 → 0.74 → 0.63 …), fading toward zero. Here, addition with \(f=1\) means no fade at all.
4
The gradient rides along. Because \(\partial c_t/\partial c_{t-1} = f = 1\), the learning signal passes back through every step with factor 1 — no vanishing. That single design choice — carry the memory by addition, gated by a value the network can set to 1 — is the whole reason the LSTM works. Everything else is bookkeeping.

🛠️ From scratch: the update, in two lines

c = f*c_prev + i*g          # additive memory update  ->  gradient highway
h = o*np.tanh(c)            # gated readout: reveal part of the memory

# backward: d c_{t-1} = dc * f   (near 1 when the network chooses to remember)
The payoff, measured. On the "remember the first bit across 30 steps" task — where our plain RNN scored about 0.66 (barely better than a coin flip) — the from-scratch LSTM reaches 1.00. Same task, same training budget; the only difference is the additive cell state. A small trick makes it reliable: start the forget gate biased open (toward 1), so the cell remembers by default.

⚠️ Mistakes everyone makes here

  • Thinking the LSTM has more "memory" because it's bigger. It's not the size — it's the additive update. A plain RNN with the same number of units still forgets, because it multiplies-and-squashes instead of adding.
  • Mixing up the two states. The cell state (\(c\)) is the protected long-term belt; the hidden state (\(h\)) is what gets read off it and passed out each step. They're different things.
  • Reading gates as on/off switches. Gates are smooth dials between 0 and 1 (they're sigmoids), and they're learned — the network decides, per step and per unit, how far to open each one.
  • Ignoring the forget-gate bias. Initializing the forget gate to open (bias ≈ 1) is a small, well-known trick that makes long-range learning reliable. Skip it and the memory half-fades before the network learns to keep it.

🔑 Key results to remember

  • The LSTM adds a cell state updated by \(c_t = f\odot c_{t-1} + i\odot g\) — additive, so gradients survive.
  • Three gates (0–1 dials): forget \(f\) (keep old memory), input \(i\) (write new), output \(o\) (read out). All learned.
  • \(\partial c_t/\partial c_{t-1} = f\): set \(f\approx 1\) and the gradient's per-step factor is ≈1 — the cure for vanishing.
  • Forget-bias open (remember by default) makes long-range training reliable.
  • Result: LSTMs learn dependencies hundreds of steps long, and powered a decade of language and speech models.

🧩 Check your understanding
Answer from memory, then read why.

Q1. What is the single most important reason the LSTM avoids vanishing gradients?

  • It uses more parameters.
    More parameters don't fix gradient flow; the update rule does.
  • It uses ReLU instead of tanh.
    LSTMs still use sigmoid and tanh; the fix isn't the activation.
  • Its cell state updates by addition (\(c_t=f\,c_{t-1}+i\,g\)), giving the gradient a near-constant path.
    Correct. The additive carry makes the per-step factor ≈ \(f\); with \(f\approx1\) the gradient neither vanishes nor explodes.
  • It reads the sequence backwards.
    Direction doesn't solve vanishing; the additive memory does.

Q2. A unit's forget gate is close to 1. What does that unit do?

  • Carries its old memory forward almost unchanged.
    Correct. \(c_t \approx c_{t-1}\) when \(f\approx1\) and little is written — the unit preserves what it stored.
  • Erases its memory.
    Erasing happens when \(f\approx0\); this is the opposite.
  • Doubles its memory each step.
    The gate scales by at most 1; it can't amplify the stored value this way.
  • Stops producing any output.
    Output is controlled by the separate output gate, not the forget gate.

Q3. Which gate decides how much of the memory becomes this step's output \(h_t\)?

  • The forget gate \(f\).
    \(f\) controls what old memory to keep, not what to reveal.
  • The input gate \(i\).
    \(i\) controls writing new information, not reading out.
  • The candidate \(g\).
    \(g\) is the proposed new content, not a gate.
  • The output gate \(o\), via \(h_t=o\odot\tanh(c_t)\).
    Correct. The output gate decides how much of the (squashed) cell state to expose.

Q4. Why initialize the forget-gate bias so it starts open (near 1)?

  • To make the model smaller.
    Bias initialization doesn't change model size.
  • So units remember by default, giving the gradient an open highway early in training.
    Correct. A positive forget bias makes \(f\) start near 1, so memory persists and long-range gradients flow before the gates have learned — a well-known, effective trick.
  • To force the model to forget everything.
    That's the opposite; open forget gate means remember.
  • Because sigmoid requires it.
    Sigmoid works with any bias; this is about training dynamics.

✍️ Practice

1. (warm-up) In the interactive, set the forget gate to 1 and the input gate to 0, and note the memory after 16 steps. Now lower the forget gate to 0.8. Roughly what's left after 16 steps, and why?

Show solution

At \(f=1,\,i=0\) the memory stays at 1 forever — perfect retention. At \(f=0.8\) it decays like \(0.8^{16}\approx0.03\), nearly gone, because each step keeps only 80% of what was there. This is the forget gate acting as a "memory half-life" dial: 1 means keep forever, lower means fade. The LSTM's power is that the network can learn to set \(f\) near 1 for the things worth remembering and lower for the rest.

2. (transfer) Run lstm.py — it trains both a plain RNN and an LSTM at length 30. Then set the LSTM's forget-bias to 0 (edit self.bf) and retrain. What changes?

Show solution

With forget-bias 0, the forget gate starts around 0.5, so memory half-fades each step (\(0.5^{30}\) is about a billionth) and early training struggles to connect step 0 to step 30 — accuracy is lower and learning slower, though it can eventually recover as it learns to open the gate. With the bias open it starts in the "remember" regime and learns fast and reliably. The experiment shows initialization isn't cosmetic: for long dependencies it can be the difference between learning and not.

3. (stretch) The cell-state update \(c_t=f\,c_{t-1}+i\,g\) looks a lot like a residual/skip connection. Explain the parallel and why it matters.

Show solution

A residual block computes \(x + F(x)\): the input flows through untouched (a factor-1 path) while \(F\) adds a correction. The LSTM does the same across time — the old memory \(c_{t-1}\) flows forward (scaled by \(f\approx1\)) while \(i\,g\) adds new content. Both create an additive highway that lets the gradient skip the squashing nonlinearity, the universal remedy for vanishing gradients — whether the depth is in layers (ResNet) or in time (LSTM). Recognizing these as one idea in two costumes is exactly the sort of insight that makes later designs (highway networks, the Transformer's residual stream) feel natural rather than arbitrary.

🚀 In the real world & at the frontier

From roughly 2014 to 2018, LSTMs were the workhorse of applied sequence modeling — Google Translate ran on them, as did much of speech recognition and text generation. Transformers have largely replaced them for very large language models, but LSTMs remain excellent where sequences are long-but-streaming or compute is tight (on-device speech, time-series forecasting, control systems). And the core lesson — protect a memory with an additive, gated path — never went away: it lives on in the residual connections at the heart of every Transformer, and in the gated update rules of today's state-space models (Track 24). Few 1997 ideas are still this load-bearing in 2020s AI.

Recap — say it to a friend

"An LSTM adds a protected memory belt that's carried forward by addition and nudged by three learned valves — keep, write, read — so both information and the learning signal can travel across hundreds of steps without fading."
