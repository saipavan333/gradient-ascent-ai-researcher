💻 How the code works

Every implementation comes in two forms so you can run it however you like:

Local Python — scripts in code/ with a requirements.txt (run pip install -r requirements.txt, then python file.py).  Colab — matching notebooks in notebooks/track-1/ you can open in Google Colab with no setup. Each lesson tells you exactly which file to run.
