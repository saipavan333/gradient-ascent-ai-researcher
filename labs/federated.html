Federated Learning

Train one shared model across many devices — without any raw data ever leaving them. Each client learns a little on its own private slice, sends only the model update, and a server averages them into a global model that has, in effect, seen everyone's data.

▸ Do this
Press Train. Each coloured client only ever sees its own region of points.
◈ You'll see
The shared line fits all the clients' data and converges to the true trend — even though no client saw the whole picture and no raw data moved.

Press Train — the clients learn locally and only send updates to be averaged.
What's happening: each round, every client takes a few gradient steps on its own data and sends only the resulting weights; the server averages them (FedAvg) and broadcasts the new global model. Since each client holds a different slice, the average ends up fitting the whole distribution — privacy-preserving training with data that never centralises. This is Federated Averaging.
