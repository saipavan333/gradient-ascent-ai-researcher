Press ▶ Train. The agent knows nothing yet — watch it discover the goal.
What's happening: the agent stores a value Q(state, action) for every move. After each step it nudges that value toward reward + the best value it can reach next — the Bellman update. Rewards at the goal slowly ripple backward until every cell knows which way to go. Early on it explores randomly; as exploration decays it exploits what it learned. This is Q-learning.
