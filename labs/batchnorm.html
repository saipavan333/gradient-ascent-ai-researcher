Batch Normalization

Deep networks train badly when the numbers flowing through them drift too big, too small, or off-centre. Batch normalization is a simple fix applied at each layer: recentre and rescale the activations so every layer receives a clean, stable distribution — then let the network stretch it back if it wants.

Drift the raw activations, then toggle BatchNorm and watch them re-centre.
What's happening: for a batch of activations x, BatchNorm computes the batch mean μ and std σ, normalizes x̂ = (x − μ)/σ (giving mean 0, variance 1), then outputs y = γ·x̂ + β with learnable γ and β. The normalization keeps every layer's inputs in a predictable range (faster, more stable training and a mild regularizing effect); γ and β hand control back to the network so it can undo the normalization when that's actually useful. This is Batch Normalization. Same fixed sample each time so you can isolate each knob.
