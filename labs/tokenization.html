Tokenization: Byte-Pair Encoding

Before a language model sees text, the text is chopped into tokens. Byte-pair encoding learns these pieces by repeatedly merging the most common adjacent pair — so frequent chunks become single tokens and rare words still split into known parts.

▸ Do this
Type a word, then slide merges applied from 0 upward.
◈ You'll see
Start as loose characters; each merge fuses a common pair (like e+r → er) into one token — until common words are a single piece.
—tokens
each pill = one token
—
What's happening: BPE is trained on a corpus by counting every adjacent symbol pair, merging the most frequent into a new symbol, and repeating thousands of times. The ordered list of merges is the vocabulary. Applying it to new text greedily fuses the same pairs — so "the" is one token while a rare word breaks into subwords, and there is never an unknown word. This is Tokenization & BPE.
