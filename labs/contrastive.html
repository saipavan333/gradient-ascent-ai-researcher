Contrastive Learning

How do you learn from data with no labels? Show the model two versions of the same thing and teach it just one rule: pull matching pairs together, push everything else apart. Structure falls out on its own.

▸ Do this
Press Run. Each colour is one item, shown as two "views" (two dots).
◈ You'll see
The two views of each item snap together and different items push apart — the embedding organises into clean clusters with no labels at all.
same colour = two views of one item
Press Run and watch matching pairs attract while everything else repels.
What's happening: each item is augmented into two views; the contrastive loss maximises agreement between the two views of the same item while minimising it with all others. Minimising that loss is a tug-of-war of attractive and repulsive forces — and its equilibrium is a space where similar things sit together. That's how self-supervised models like SimCLR learn useful features without a single label. This is Contrastive Learning.
