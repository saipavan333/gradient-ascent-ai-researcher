RNN Memory: Vanishing & Exploding

A recurrent network reads a sequence one step at a time, carrying a hidden "memory" forward. But that memory has a problem: nudge the recurrence weight below 1 and early signals fade to nothing; above 1 and they blow up. This is why plain RNNs forget.

▸ Do this
A pulse enters at step 0. Slide the memory weight and the sequence length.
◈ You'll see
Weight < 1 → the memory fades (vanishing gradient, forgetting). Weight = 1 → it holds. Weight > 1 → it explodes.

What's happening: the hidden state updates as ht = tanh(w·ht−1 + xt). With one pulse at the start, h shrinks by roughly a factor of w each step — so after many steps only a weight near 1 preserves it. The same factor multiplies the gradient on the way back, which is exactly the vanishing/exploding gradient problem that LSTMs and GRUs were invented to fix. This is Vanishing Gradients.
