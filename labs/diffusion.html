Diffusion: Noise ⇄ Data

How image generators actually work. Forward, a picture is destroyed into pure static, one small step of noise at a time. A model then learns to run that tape backward — turning random static into something real.

▸ Do this
Drag the time slider from data to noise and back — or press Play to watch the full forward-then-reverse cycle.
◈ You'll see
The glowing shape melts into a random cloud as time runs forward, and re-condenses out of pure noise as time runs backward.
left ← data · noise → right
Drag the slider right to add noise. All the way = pure static; a generator learns to reverse it.
What's happening: each particle's position is √ᾱ·(shape) + √(1−ᾱ)·(noise) — a blend that slides from the true shape (ᾱ=1) to pure Gaussian noise (ᾱ=0) as time runs forward. Training a diffusion model means learning to predict the noise at each step so it can be subtracted, walking back up the chain. This is Diffusion models, made tangible.
