Backprop: the Chain Rule, Alive

Every neural network learns by one trick: run numbers forward through a graph, then send gradients backward to see how each input pushed the output. Drag the inputs and watch both passes update instantly.

▸ Do this
Drag the inputs a, b, c. Watch the green forward values and the orange gradients.
◈ You'll see
Each node's gradient is how much the final output L would change if you nudged that node — the chain rule multiplying local slopes along every edge.
green = forward value · orange = gradient (∂L/∂·)
—
What's happening: the graph computes e = a×b, then d = e + c, then L = d. Backprop starts with ∂L/∂L = 1 and walks backward: a + gate passes the gradient straight through, and a × gate swaps the values (∂L/∂a = b, ∂L/∂b = a). Stack millions of these and you have a trainable network. This is Backpropagation, one node at a time.
