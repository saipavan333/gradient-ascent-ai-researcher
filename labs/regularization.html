Regularization: Why L1 Makes Things Sparse

Adding a penalty on the size of the weights keeps a model from over-fitting — but the shape of the penalty matters. L2 (ridge) gently shrinks every weight; L1 (lasso) drives some weights exactly to zero, doing feature selection for free. This one picture explains why.

▸ Do this
Toggle L1 vs L2 and raise the penalty λ. Watch the solution dot move from the unregularized best fit toward the origin.
◈ You'll see
L2's penalty region is a circle, so the solution shrinks smoothly with both weights alive. L1's region is a diamond — its pointy corners sit on the axes, so the solution snaps onto an axis and a weight becomes exactly 0.

Toggle L1/L2 and raise λ.
What's happening: training minimizes data-fit loss (the blue elliptical rings, centered on the unpenalized best fit w★) plus λ times a penalty on the weights. Geometrically, the solution is where a loss ring first touches the penalty "budget" region. L2 penalizes w₁²+w₂² — a round region, so the contact point slides smoothly and both weights stay nonzero (shrinkage). L1 penalizes |w₁|+|w₂| — a diamond whose corners lie on the axes, so the first contact is usually a corner, forcing a weight to exactly 0. That's why L1 yields sparse, self-selecting models. Bigger λ = smaller budget = more shrinkage. This is Regularization.
