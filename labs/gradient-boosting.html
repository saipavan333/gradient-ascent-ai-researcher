Gradient Boosting: Fixing Your Own Mistakes

Instead of one big model, gradient boosting builds a team of tiny ones — but sequentially. Each new little tree is trained to predict the errors the team has made so far. Add it in, and the errors shrink. Repeat, and a stack of weak stumps becomes a strong predictor.

▸ Do this
Press Add tree (or Auto) to add one stump at a time, each fit to the current residuals.
◈ You'll see
The prediction (gold staircase) climbs toward the target and the residual bars (red) shrink round by round. A few dozen tiny steps add up to a close fit.

Add trees and watch the residuals shrink.
What's happening: we start with a flat prediction (the average). Each round we compute the residuals — how far off each point still is — and fit a small regression tree (here a one-split stump) to those residuals, then add a fraction (the learning rate) of it to the running prediction. Fitting the residuals is literally taking a gradient-descent step on the squared-error loss in function space — hence "gradient" boosting. Small learning rates plus many trees generalize best (each tree corrects a little, so no single one overfits). This sequential error-correction is what makes boosted trees (XGBoost, LightGBM) dominate tabular ML. This is Boosting.
