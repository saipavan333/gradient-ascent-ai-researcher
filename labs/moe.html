Mixture of Experts

How do you make a model enormous without making it slow? Keep many specialist "experts" but, for each input, wake up only a couple. A little gate decides who handles what — giant capacity, tiny compute per token.

▸ Do this
Drag the white input around the space.
◈ You'll see
The gate routes it to the nearest 2 experts, which light up; the rest stay asleep. Each expert owns a region of the input space.
colours = each expert's territory · lit = active for this input
Drag the input dot — only the two nearest experts activate for it.
What's happening: the gate scores every expert by how well it matches the input (here, closeness) and softmaxes those scores; only the top-k experts actually run, weighted by the gate. So a model can hold billions of parameters across hundreds of experts yet spend the compute of just a few per token. This is how frontier models scale — Mixture of Experts.
