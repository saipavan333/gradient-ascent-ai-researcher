Line of Best Fit

The simplest model there is: a straight line. Tilt it by hand to fit the dots, then let the computer find the exact best fit by minimising the squared error — the total length of the little red drop-lines.

▸ Do this
Drag the slope and height to fit the cloud by eye — then press Best fit to let gradient descent finish the job.
◈ You'll see
The red drop-lines (residuals) shrink and the loss falls to its lowest possible value when the line threads the points.
—loss (mean sq. error)
—best possible
red drop-lines = errors the line is making
Tilt the line to fit the dots, then press Best fit.
What's happening: for a line y = slope·x + height, the loss is the average squared drop-line. It's a smooth bowl in (slope, height) space, so gradient descent slides straight to the one lowest point — the least-squares fit. Logistic regression uses the same idea but bends the line through a sigmoid to output a probability. This is Linear & Logistic Regression.
