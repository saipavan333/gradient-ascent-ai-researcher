t-SNE: Unfolding Hidden Structure

Some patterns are invisible to straight-line methods like PCA. t-SNE is a nonlinear map that cares only about who your neighbors are — it pulls points that were close together into tight clusters and pushes everything else apart, revealing structure that a linear projection would smear.

What's happening: t-SNE first turns high-dimensional distances into neighbor probabilities — for each point, nearby points get high probability, far ones near zero (a Gaussian around each point). Then it lays points out in 2D and moves them so the 2D neighbor probabilities (using a heavy-tailed Student-t curve) match the originals, by gradient descent on their mismatch (a KL divergence). Because it only tries to preserve local neighborhoods, it can tear apart globally-entangled structures like these rings — each ring's points stay together and drift away from the others. It's the go-to tool for visualizing embeddings from deep nets; just remember cluster sizes and distances in a t-SNE plot aren't meaningful. This is Dimensionality reduction.
