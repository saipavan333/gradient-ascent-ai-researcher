Autoregressive Generation

Every GPT writes the same way: one token at a time, each new token chosen from a probability distribution conditioned on everything written so far, then fed back in as input. Here's that loop laid bare with a tiny character model you can watch think.

▸ Do this
Press Generate (or Auto). Each step shows the model's next-character distribution; one is sampled and appended. Try changing the temperature.
◈ You'll see
The text grows character by character, each conditioned on the last few. Low temperature = safe and repetitive; high temperature = adventurous and messier. The output feeds back as the next input — that's "autoregressive".
top: generated text so far · bottom: next-character probabilities, sampled one highlighted
Press Generate to grow the text one character at a time.
What's happening: we trained a tiny character-level model (it just counts, for each pair of recent characters, which character tends to come next) on a fixed passage. To generate, it looks at the last couple of characters, produces a probability for every possible next character, divides the log-probabilities by the temperature and samples one, appends it, and repeats — feeding its own output back as input. That feedback loop is what "autoregressive" means, and it's exactly how large language models generate, only with a giant neural network instead of a lookup table. Because this model is tiny it soon rambles — which is the whole reason scale and better architectures matter. This is Autoregressive generation.
