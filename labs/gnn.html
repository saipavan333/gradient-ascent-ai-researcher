Graph Neural Networks: Message Passing

How do you run a network on a shape with no rows or columns — a social graph, a molecule, a road map? Each node repeatedly gathers a message from its neighbours and updates itself. Light one node and watch the signal ripple across the graph.

▸ Do this
Click a node to light it up, then press Step (or Run) to pass messages.
◈ You'll see
The glow spreads to neighbours, then their neighbours — fast within a tight cluster, slower across the lone bridge. After a few rounds every node "knows" about the source.

Click any node to light it, then Step to watch the message spread to its neighbours.
What's happening: one round of a GNN updates every node to a blend of its own value and the average of its neighbours' — a message-passing step. Stack a few rounds and each node's representation absorbs information from further and further away in the graph. Because it only ever looks along edges, the same network handles any graph shape or size. This is Message Passing.
