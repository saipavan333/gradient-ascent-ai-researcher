Value Iteration: Planning with the Bellman Equation

Give an agent a map — where the rewards are, where the walls are — and it can compute the best move from every square without taking a single step. Value iteration floods the grid with value spreading out from the goal, and the optimal policy falls out for free.

▸ Do this
Press Step to run one Bellman sweep at a time (or Auto). Adjust the discount γ to change how far-sighted the agent is.
◈ You'll see
Value (colour) spreads outward from the goal, flowing around the walls and away from the pit. The arrows — the optimal policy — snap to point along the best path to the goal.

Press Sweep to propagate value from the goal.
What's happening: the world is a Markov decision process — states (squares), actions (up/down/left/right), rewards, and a discount γ. Value iteration repeatedly applies the Bellman optimality update V(s) ← maxₐ [ r + γ·V(s′) ]: the value of a square becomes the best you can do by taking one step and then acting optimally forever after. Each sweep pushes value one square further from the goal, and after enough sweeps V stops changing (it has converged). Reading the best action at each square gives the optimal policy (arrows). Unlike Q-learning, which must explore to learn, value iteration plans directly from a known model — the dynamic-programming heart of RL. This is Value iteration & MDPs.
