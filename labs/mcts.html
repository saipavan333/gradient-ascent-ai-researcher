Monte Carlo Tree Search

You can't search a whole game tree — it's astronomically large. MCTS, the algorithm behind AlphaGo, grows the tree selectively: it spends its effort on the most promising moves, using quick random playouts to estimate how good each one is, and lets the winners attract more attention.

▸ Do this
Press Rollout (or Auto) to run one search iteration: select a branch, simulate a random playout, and back up the result.
◈ You'll see
Nodes grow with visits. The search quickly stops wasting time on weak branches and pours rollouts into the best line — its size shows the move it now recommends.

Press Rollout to grow the search tree.
What's happening: each rollout runs four steps. Select: from the root, walk down by picking the child with the best UCB score — average value + C·√(ln N / n) — which balances exploiting good moves against exploring rarely-tried ones. Expand a new node, simulate a fast (here random) playout to a result, and back-propagate that result up the path, bumping every ancestor's visit count and value. Over many rollouts the visit counts concentrate on the strongest line, and the most-visited child of the root becomes the recommended move. Swap the random playout for a neural network's value estimate and you have the core of AlphaGo/AlphaZero. This is Monte Carlo Tree Search.
