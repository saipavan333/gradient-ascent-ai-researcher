KL Divergence: Distance That Isn't Symmetric

KL divergence measures how many extra bits you waste when you encode data from one distribution using a code built for another. It's the loss function hiding inside cross-entropy, variational inference, and RLHF — and its most surprising property is that it's not symmetric.

▸ Do this
Slide Q's mean and width away from the fixed P, and watch both KL(P‖Q) and KL(Q‖P).
◈ You'll see
The two numbers are different — order matters. Both hit zero only when Q exactly matches P. Making Q too narrow where P has mass is punished harshly.

blue = P (fixed) · orange = Q (you control) · shaded = where they disagree
Move Q and watch the two divergences differ.
What's happening: KL(P‖Q) = ∫ p(x) log[p(x)/q(x)] dx — the average, weighted by P, of the log-ratio between the two densities. It is always ≥ 0 and equals 0 only when Q = P everywhere. It is not a true distance because it isn't symmetric: KL(P‖Q) ≠ KL(Q‖P). The reason is the weighting — KL(P‖Q) is dominated by regions where P is large, so it blows up if Q is nearly zero where P isn't ("mode-covering"); KL(Q‖P) is weighted by Q instead ("mode-seeking"). Which direction you minimize changes what your model learns. For two Gaussians there's a clean closed form, which is what we plot. This is KL divergence.
