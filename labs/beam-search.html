Beam Search Decoding

A language model gives a probability for every next word. Greedy decoding grabs the single best word each step and can paint itself into a corner. Beam search keeps the few most promising whole sequences alive at once — trading a little compute for much better sentences.

▸ Do this
Slide the beam width and press Step to expand the search one level at a time (or Auto).
◈ You'll see
Width 1 is greedy — it follows one path and can miss the best sentence. Widen the beam and a higher-scoring path (gold) survives that greedy would have thrown away.
—best sequence score (log-prob)
—best sequence so far
nodes = words · gold = the surviving beams · number = log-prob of the path
Pick a beam width and press Step.
What's happening: each path's score is the sum of the log-probabilities of its words (adding logs = multiplying probabilities). At every level we expand all live beams, then keep only the top-k by score — that k is the beam width. Greedy (k=1) commits to the locally-best word and can be trapped; a wider beam carries a slightly-worse first word that pays off later. This is exactly how LLM decoding balances quality against cost. This tree uses fixed, hand-set probabilities so you can see the trap.
