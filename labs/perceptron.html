The Perceptron Learning Rule

The perceptron (1958) is the ancestor of every neural network — a single neuron that learns to separate two classes with one astonishingly simple rule: whenever it gets a point wrong, nudge the boundary toward that point. Watch a line teach itself.

▸ Do this
Press Train (or Step). Each update grabs one misclassified point and rotates the boundary to fix it.
◈ You'll see
The boundary swings around and — because the data is separable — settles into a line with zero mistakes. The convergence theorem guarantees it stops in finite steps.

What's happening: the neuron predicts sign(w·x + b). The perceptron rule: for a misclassified point x with true label y (±1), update w ← w + η·y·x and b ← b + η·y — literally shifting the boundary toward getting that point right. Rosenblatt's convergence theorem proves that if the two classes can be separated by a line, this rule finds a separating line in a finite number of updates. Its one famous limitation — it can't solve XOR or anything not linearly separable — is what motivated multi-layer networks and, eventually, deep learning. This is the Perceptron.
