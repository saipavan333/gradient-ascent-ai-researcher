The Growing Receptive Field

Each neuron in a convolutional network only looks at a small patch of the layer below it. But stack a few layers and a single deep neuron ends up "seeing" a wide swath of the original image — that expanding window is the receptive field, and it's why deep CNNs perceive both fine detail and big-picture context.

Add layers and watch the cone widen.
What's happening: a convolution with kernel size k means each neuron reads k neighbours from the layer below. Trace one neuron down: layer by layer, the set of inputs it depends on grows by (k−1) on top of the previous window, so after L layers (stride 1) the receptive field is 1 + L·(k−1) pixels wide. That's why early layers detect edges and textures (tiny fields) while deep layers respond to whole objects (huge fields). Bigger kernels, more depth, striding, and dilation all enlarge it faster — the central knob CNN architects tune so the network's "view" matches the size of the thing it must recognize. This is CNN receptive fields.
