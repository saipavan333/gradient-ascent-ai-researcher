Newton's Method vs Gradient Descent

Gradient descent only knows which way is downhill, so it inches along. Newton's method also senses the curvature — it fits a parabola to the spot it's standing on and jumps straight to that parabola's bottom. The result: a handful of giant, well-aimed steps instead of hundreds of timid ones.

Set a start, then press Step repeatedly (or Auto). Gold = Newton, grey = gradient descent, from the same point.
◈ You'll see
Newton's dashed parabola hugs the curve and it lands near the minimum in ~4 steps; gradient descent is still crawling. That speed is why second-order methods are prized — when you can afford the curvature.

What's happening: to minimize f, gradient descent uses only the slope f′: x ← x − η f′(x), a fixed cautious step. Newton's method also uses the second derivative f″ (the curvature) to build the local parabola and jump to its vertex: x ← x − f′(x)/f″(x). On a perfect parabola that's one step to the exact minimum; on a general curve it converges quadratically — the number of correct digits roughly doubles each step. The catch is you need f″ (here a single number; for a big model it's a huge matrix), which is why deep learning mostly uses cheaper first-order methods with momentum. This is Optimization.
