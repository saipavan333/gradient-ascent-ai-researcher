Quantization: Fewer Bits, Almost the Same Model

A model's weights are stored as high-precision numbers, but most of that precision is wasted. Quantization snaps every weight to one of a small set of levels, so each needs only a few bits — shrinking the model 4–8× and speeding it up, with surprisingly little loss.

Lower the bits per weight. The smooth weight profile (white) gets snapped to the available levels (gold staircase).

At 8 bits the staircase is indistinguishable; drop toward 2–3 bits and visible steps appear as error grows — but memory falls in step. The sweet spot keeps quality while slashing size.

What's happening: with b bits you get 2ᵇ distinct levels spread across the weight range; every weight is rounded to the nearest level, so it can be stored as a small integer index instead of a 32-bit float. Here we quantize a smooth weight profile: at 8 bits (256 levels) the rounding is invisible; drop to 3 bits (8 levels) and the staircase — and the error — become obvious, while memory shrinks to b⁄32 of the original. Real quantization is cleverer (per-channel scales, calibration, keeping outliers) and routinely runs big models at int8 or even int4 with tiny accuracy loss, which is what lets large models run on phones and cheap GPUs.
